# Example 69 - 금액 계산: 정수 센트 (부동소수점 회피) (Punk + Perl)

금액을 **정수 센트(cents)** 로 다루어 부동소수점 오차 없이 세금/합계를 계산하는 예제입니다.
반올림 규칙(half-up)을 코드에 명시했습니다.

- `"1.23"` → `123` 센트
- `"1.235"` → `124` (half-up), `"1.234"` → `123`
- 세율은 퍼센트 문자열(`"7.5"`)
- 사람이 읽는 형식(`"10.75"`)도 함께 반환

## 동작 방식 (왜 이렇게 될까)

### 왜 정수인가

`0.1 + 0.2 != 0.3` (부동소수점). 돈 계산에 float 를 쓰면 센트가 어긋납니다. 그래서
**최소 단위(센트) 정수**로 저장/계산합니다.

### 십진 문자열 파싱 + 반올림

소수 셋째 자리를 보고 **round-half-up** 합니다.

```perl
my $fr = substr($frac . '00', 0, 3);
my $cents = int($int) * 100 + int(substr($fr, 0, 2));
$cents++ if substr($fr, 2, 1) ge '5';
```

### 세금도 정수 연산

세율을 만분율 정수(`7.5%` → `750`)로 바꾸고, `(cents*bp + 5000)/10000` 를 정수로
내림하여 반올림합니다. float 를 곱하지 않습니다.

```perl
return int(($cents * $bp + 5000) / 10000);
```

### 표시와 계산 분리

내부는 센트 정수, 표시는 `sprintf('%d.%02d', ...)` 로 변환합니다. 통화 기호/로케일은
표시 계층의 일입니다.
