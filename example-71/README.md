# Example 71 - 슬러그 생성과 유일성 (Punk + Perl)

제목에서 **URL 슬러그**를 만들고 유일성을 보장하는 예제입니다. 자동 생성은 충돌 시
`-2`, `-3` 을 붙이고, 사용자가 명시한 슬러그가 중복이면 `409 Conflict` 를 돌려줍니다.

- `"Hello World!"` → `hello-world`
- 같은 제목 반복 → `hello-world-2`, `hello-world-3`
- 명시 슬러그 중복 → `409`
- 제목 없음 → `400`

## Routes

| Method | Path         | Description |
|--------|--------------|-------------|
| GET    | /api/ping    | ping/pong |
| GET    | /api/healthz | k8s liveness |
| GET    | /api/readyz  | k8s readiness |
| POST   | /posts       | 글 생성(슬러그) |
| GET    | /posts/:slug | 슬러그로 조회 |

## 동작 방식 (왜 이렇게 될까)

### 슬러그 정규화

소문자화 → 영숫자 외 문자를 `-` 로 → 양끝 `-` 제거. 빈 결과는 `post` 로 대체합니다.

```perl
$s = lc($s // '');
$s =~ s/[^a-z0-9]+/-/g;
$s =~ s/^-+|-+$//g;
```

### 두 가지 충돌 정책

- **자동 생성**: 사용자가 신경 쓰지 않아도 되므로 조용히 `-2` 를 붙여 유일화
- **명시 슬러그**: 사용자가 의도한 값이므로 임의 변경하지 않고 `409` 로 알림

이 구분이 중요합니다. 자동은 관대하게, 명시는 엄격하게.

### 409 Conflict

같은 자원이 이미 있어 생성이 충돌할 때의 표준 상태 코드입니다.

```perl
if (exists $POSTS{$slug}) { ... 409 ... }
```
